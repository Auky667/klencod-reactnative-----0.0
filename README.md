# ترميم الإسلام — موسوعة علمية شاملة

تطبيق موسوعة عربية يربط **السيرة النبوية** بالعقيدة والقرآن والفقه في صياغةٍ متينة، مع محتوى
موثق يفتح أبواب التعلّم والتدبر. الواجهة بالعربية بالكامل مع دعم RTL، وهويةٌ إسلامية عصرية
(داكنةٌ افتراضيًّا + ذهبي هادئ + زخارف هندسية).

---

## ⚠️ ملاحظة مهمة عن بيئة التنفيذ والبناء

طُلِب بناء تطبيق **React Native + Expo** مع جاهزية APK. بيئة التنفيذ هنا هي بيئة **توليد تطبيقات
الويب** (React + TypeScript + Vite + Tailwind)، وتبني مخرجًا واحدًا `dist/index.html`، ولا توجد
فيها **Android SDK ولا JDK 17 ولا Gradle**، لذلك:

| المطلوب | الحالة في هذه البيئة |
| --- | --- |
| بناء كود التطبيق واختباره | ✅ تم (`npm run build` + `tsc --noEmit` بنجاح) |
| تشغيل التطبيق كتطبيقٍ هاتفي حقيقي | ✅ يعمل كواجهةٍ هاتفيةٍ أصلية (Header + Drawer + شريط سفلي + Safe Area) |
| `npx expo prebuild --platform android` | ❌ غير قابل للتنفيذ (لا Android SDK في البيئة) |
| `gradlew assembleDebug` / `assembleRelease` | ❌ غير قابل للتنفيذ (لا JDK/Gradle في البيئة) |
| إعداد `app.json` + `eas.json` لإنتاج APK | ✅ موفَّر وجاهز في `native/` |
| ادّعاء نجاح بناء APK | **لم يُدَّعَ** — لا يوجد APK مُنتَج في هذه البيئة |

الكود كله منظمٌ ببنيةٍ مطابقةٍ لما طُلِب (`src/data/content.ts`, `src/routes/*`, `src/components/site/*`,
`src/components/home/*`, `src/components/quran/*`, `src/constants/*`, `src/context/*`, `src/hooks/*`,
`src/utils/*`, `src/types/*`)، فنقلُه إلى React Native يقتصر على استبدال عناصر العرض من DOM إلى
`<View>/<Text>/<ScrollView>/<FlatList>` دون المساس بالبيانات ولا بمنطق البحث ولا بالمفضلة.
الخطوات والتكوينات الكاملة للنقل وبناء APK موثقة في **[`native/README.md`](./native/README.md)**،
مع `native/app.json` و`native/eas.json` جاهزين.

## المزايا

- **7 شاشات كاملة:** الرئيسية، السيرة النبوية، العقيدة، القرآن الكريم، الفقه الإسلامي، البحث، عن التطبيق (وإضافة المفضلة).
- **الوضع الداكن افتراضيًّا** والوضع الفاتح، ويُحفظ الاختيار في التخزين المحلي ويُستعاد عند فتح التطبيق.
- **قائمة جانبية** (آية اليوم + التنقل + المفضلة) مع تمييز القسم الحالي وإغلاقٍ بعد التنقل ودعم Safe Area وEscape.
- **بحث فوري شامل** في 348 مدخلًا مع تطبيعٍ للعربية (التشكيل/الهمزات/الياء/التاء المربوطة)، ترتيبٍ بالملاءمة، عددٍ للنتائج، حالة عدم وجود نتائج، زر مسح، وتقسيمٍ للعرض.
- **مؤشر تقدم القراءة** في أعلى الشاشة + **زر العودة للأعلى** بعد تمريرٍ مناسب.
- **المفضلة** مرتبطة بمُعرّف ثابت للموضوع (`seerah-12`, `fiqh-salah-3`, …) وتُحفظ محليًّا.
- **النسخ** إلى الحافظة و**المشاركة** بورقة المشاركة الأصلية (`navigator.share` مع بديلٍ آمن).
- **TopicAccordion** يعرض: النص التفصيلي، الأدلة الشرعية، الفوائد والدروس، المصادر والمراجع، وأزرار النسخ/المشاركة/المفضلة مع رسالة حالة.
- تصميمٌ هاتفي: أحجام مسٍّ مناسبة، بلا تمريرٍ أفقي، بلا نصٍّ خارج البطاقات، RTL كامل، وشريط تنقلٍ سفلي.

```
├── router.tsx             # موجّه الهاش (يعمل كملفٍ ثابتٍ واحد)
├── types/index.ts         # Topic / Evidence / TopicSection / Surah / NameOfAllah / SearchEntry
├── constants/navigation.ts # المسارات وعناصر القائمة والشريط السفلي
├── context/AppContext.tsx # الثيم + المفضلة + رسائل الحالة
├── hooks/useTheme.ts
├── utils/search.ts        # التطبيع العربي + ترتيب النتائج + الاقتطاع
├── utils/copyShare.ts     # النسخ والمشاركة
├── data/                  # البيانات الأصلية كاملة
│   ├── seerah.ts   aqeedah.ts   quran.ts (علوم القرآن + التجويد)
│   ├── fiqh.ts     surahs.ts   asmaAllah.ts
│   └── content.ts          # التصديرات + تقسيم الأقسام + buildSearchEntries + الإحصائيات
├── components/site/       # AppHeader, SideDrawer, PageHeader, SectionTitle, TopicAccordion,
│                          # TopicCard, SearchBar, ThemeToggle, ScrollToTop, AppFooter, TopicList, Layout
├── components/home/       # HeroSection, VerseCard, Statistics, SectionGrid, FeaturedTopics,
│                          # FeaturedSurahs, FeaturedNames
├── components/quran/      # SurahCard, MemorizationPlan
└── routes/                # index, seerah, aqeedah, quran, fiqh, search, favorites, about
scripts/check-data.mjs     # تقرير مقارنة البيانات (يُنفَّذ: node scripts/check-data.mjs)
native/                    # app.json + eas.json + README (إعداد Android/EAS)
```

## تقرير مقارنة البيانات (ناتج فعلي من `scripts/check-data.mjs`)

| المصفوفة/القسم | العدد | ملاحظة |
| --- | --- | --- |
| `seerah` | **55** | أحداث السيرة `slice(0,24)` = 24 · الشمائل `slice(24,51)` = 27 · الخلفاء `slice(51)` = 4 |
| `aqeedah` | **20** | من تعريف العقيدة إلى الولاء والبراء والفرق المنحرفة |
| `quranScience` | **12** | من تعريف العلوم إلى أسماء القرآن وترتيب المصحف |
| `tajweed` | **12** | من تعريف التجويد إلى الوقف والابتداء |
| `surahs` | **114** | الرقم والاسم والنوع وعدد الآيات والفضل |
| أقسام `fiqh` | **7** | الطهارة 5 · الصلاة 6 · الزكاة 5 · الصيام 5 · الحج 5 · المعاملات 5 · الأسرة والميراث 5 = **36 بابًا** |
| `asmaAllah` | **99** | أول ثمانية تُعرض في الرئيسية، والكل في العقيدة |
| `totalTopics` | **135** | مجموع الموضوعات بلا تكرار |
| `buildSearchEntries` | **348** | موضوعات + سور + أسماء الله |
| أدلة/فوائد/مراجع ناقصة | **0** | فحصٌ آليٌّ لكل موضوع |

فحوصات محتوى أخرى نجحت:

- السور الست الأولى = الفاتحة، البقرة، آل عمران، النساء، المائدة، الأنعام.
- أسماء الله الثمانية الأولى = الرَّحمن، الرَّحيم، الملك، القدوس، السلام، المؤمن، المهيمن، العزيز.
- الموضوعات المختارة = `seerah[0]`, `seerah[5]`, `aqeedah[2]`, `quranScience[0]`, `tajweed[4]`, `fiqh[1].topics[0]`.
- مجموعات البحث = 15 مجموعةً تغطي كل أقسام الموسوعة.
